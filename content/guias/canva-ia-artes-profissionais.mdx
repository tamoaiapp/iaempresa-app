O Canva já era fácil. Com IA, ficou ainda mais poderoso. Você não precisa de talento artístico para criar materiais que parecem feitos por designer profissional.

## Os recursos de IA do Canva que você precisa conhecer

### 1. Magic Write (geração de texto)
Gera textos para qualquer material: slogan, descrição de produto, legenda, título de banner.

**Como usar:**
1. Abra qualquer design no Canva
2. Clique em "+ Apps" na barra lateral
3. Busque "Magic Write"
4. Descreva o texto que quer e gere

### 2. Magic Edit (edição de imagens)
Substitui partes de uma imagem descrevendo o que quer. Exemplo: muda o fundo de uma foto de produto sem sair do Canva.

**Como usar:**
1. Selecione uma imagem no design
2. Clique em "Editar foto" → "Magic Edit"
3. Pinte a área que quer mudar
4. Descreva o que quer no lugar (ex: "fundo de madeira rústica")

### 3. Text to Image (geração de imagens)
Cria imagens a partir de uma descrição em texto.

**Como usar:**
1. No Canva, clique em "Elementos"
2. Busque "Gerar imagem com IA"
3. Descreva: "produto [X] em fundo minimalista branco, fotografia profissional"

### 4. Magic Resize (redimensionamento automático)
Transforma um post de Instagram em banner de WhatsApp, story, card de LinkedIn — tudo automaticamente.

## Fluxo completo para criar um post

1. Escolha um template de "Post Instagram" no Canva
2. Troque a foto do template pela sua (ou gere com IA)
3. Use Magic Write para criar o texto do post
4. Ajuste cores para combinar com sua marca
5. Use Magic Resize para criar versões para Story e WhatsApp
6. Exporte e publique

## Resultado esperado

Em 20-30 minutos, você cria um kit completo: post feed, story, banner para WhatsApp — todos com identidade visual consistente e texto gerado por IA.

## Dica de produtividade

Salve suas cores e fontes favoritas no **Brand Kit** do Canva (disponível no plano grátis). Todos os novos materiais já vão ter sua identidade visual automaticamente.
