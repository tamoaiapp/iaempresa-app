Criar anúncio que funciona é uma das habilidades mais valiosas para um pequeno negócio. O ChatGPT não vai rodar o anúncio por você, mas vai ajudar muito na parte mais difícil: o texto.

## O que o ChatGPT pode fazer por você

- Criar o texto do anúncio (headline + descrição)
- Sugerir públicos para segmentação
- Criar variações A/B para testar
- Analisar por que um anúncio não está funcionando

## Criando o texto do anúncio

Use este prompt estruturado:

> "Crie 3 variações de anúncio para Facebook/Instagram Ads para [produto/serviço]. 
> 
> Público-alvo: [descreva: idade, localização, interesses]
> Objetivo do anúncio: [cliques no site / mensagens no WhatsApp / vendas]
> Principal benefício do produto: [descreva em 1 frase]
> Dor que o produto resolve: [descreva]
> 
> Cada variação deve ter:
> - Headline (máximo 40 caracteres)
> - Texto principal (máximo 125 caracteres para mobile)
> - Chamada para ação (CTA)
> 
> Use linguagem direta, informal, em português."

## Dica: use o framework PAS

Peça ao ChatGPT para usar o método PAS (Problema → Agitação → Solução):

> "Reescreva o anúncio usando o framework PAS: comece com o problema do cliente, agite a dor e ofereça minha solução como saída. Produto: [descreva]."

## Criando públicos com IA

> "Meu produto é [descreva]. Quem seria o cliente ideal? Sugira 3 públicos diferentes para segmentar no Meta Ads, com: faixa etária, gênero, interesses e comportamentos. Seja específico."

## Analisando resultados com ChatGPT

Se seu anúncio não estiver performando, cole os dados no ChatGPT:

> "Meu anúncio do Meta Ads tem estes resultados: CTR [X]%, CPM R$[X], CPC R$[X], taxa de conversão [X]%. O anúncio diz: [texto]. Qual o diagnóstico? O que devo testar para melhorar?"

## Resultado esperado

Textos de anúncio mais profissionais, com clareza de benefícios e CTAs fortes — sem precisar contratar uma agência para o texto.

## Importante

A IA te ajuda com o criativo, mas o sucesso do anúncio depende também de:
- Orçamento mínimo adequado (R$20-30/dia para ter dados)
- Pixel do Meta instalado no site
- Paciência para testar variações (pelo menos 7 dias por teste)
