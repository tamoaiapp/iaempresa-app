Legenda travada é um dos maiores motivos para donos de negócio abandonarem o Instagram. Você tem a foto linda mas não sabe o que escrever. O ChatGPT resolve isso em segundos.

## O prompt mágico para legendas

Abra o ChatGPT e use este modelo:

> "Crie uma legenda para Instagram para [descreva a foto/produto]. Meu negócio é [tipo de negócio]. Público-alvo: [descreva]. Tom: [escolha: animado / profissional / descontraído / inspirador]. Inclua: emojis relevantes, 1 pergunta para engajar seguidores e 5-8 hashtags relevantes em português. Tamanho: médio (100-150 palavras)."

## Exemplos prontos por segmento

### Para loja de roupas:
> "Crie uma legenda para foto de um vestido floral leve, ideal para o verão. Meu negócio é uma boutique feminina em São Paulo. Público: mulheres de 25-40 anos. Tom: animado e fashionista."

### Para restaurante / lanchonete:
> "Crie uma legenda para foto de um hambúrguer artesanal recém-preparado. Negócio: hamburgueria artesanal. Tom: apetitoso e descontraído. Inclua um CTA para fazer pedido pelo WhatsApp."

### Para salão de beleza:
> "Crie uma legenda para foto de antes e depois de uma transformação de cabelo. Salão de beleza feminino. Tom: inspirador e empoderador."

## Refinando o resultado

Se a primeira versão não ficou boa, peça ajustes:

- "Deixe mais curta, máximo 80 palavras"
- "Use um tom mais descontraído"
- "Troque as hashtags por algo mais específico para [cidade]"
- "Adicione urgência — promoção só até domingo"

## Criando legendas em lote

Para economizar mais tempo, peça 5 ou 10 legendas de uma vez:

> "Crie 5 legendas diferentes para posts sobre [tema] para o Instagram de [tipo de negócio]. Cada uma com abordagem diferente."

## Resultado esperado

Com 5 minutos por legenda (ou 20 minutos para criar 10 de uma vez), você nunca mais vai ficar com o Instagram parado por falta de texto.
